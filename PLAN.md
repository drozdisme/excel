# BatchCalc — план максимум

## Цель

Инженер нажимает одну кнопку в своей привычной книге Excel. Весь пакетный расчёт
(все позиции × наборы × load cases) выполняется нативным многопоточным движком за
секунды–минуту вместо часов. Excel при этом не замирает и не мигает. Результаты
лежат в исходных выходных листах и совпадают с Excel. Без Python, без админа,
без правки формул и методики.

## Измеримые критерии релиза

| Метрика | Excel (VBA) | Прототип коллеги | Цель |
|---|---|---|---|
| Frame STA403, frame + joints, расчёт | ~4 ч | 1434 с | **≤ 30 с** |
| Запись результатов в книгу | в конце макроса | 191 с | **≤ 20 с** |
| Shear Tie | 10 с (VBA) | Excel | в движке, ≤ 1 с |
| Совпадение с Excel | — | 16 млн ячеек, ≤ 1e-8 | **те же 16 млн, ≤ 1e-12, ошибки/текст точно** |
| Новая книга того же типа | — | новый Python-адаптер | **только конфиг** |
| Установка | — | Python-exe 38 МБ + VBA | один per-user installer, без админа |

## Архитектура

```
Excel (книга инженера)
   │ кнопка/лента (XLL add-in, per-user)
   ▼
SaveCopyAs во временный снимок (учитывает несохранённые правки)
   ▼
xlmodel   — потоковое чтение OOXML/XLSB: значения, формулы, shared/array/dynamic формулы, имена
xlformula — полный парсер формул Excel → AST → IR со ссылками, LET, массивами, spill (#)
xlcalc    — векторный движок: значение = Uniform | Lanes[N кейсов] (типизированные колонки),
            ленивый расчёт от выходов, авто-вынос инвариантов кейса, SIMD f64, точная семантика Excel
batch     — декларативный контракт: оси (позиция × набор × кейс), драйверы, выходы, адреса записи;
            планировщик задач по ядрам, бюджет памяти, отмена, прогресс
   ▼
запись в книгу: массивами в фоне, статус-бар, отмена; формулы/отчёты не трогаются
```

## Этапы (каждый закрывается измерением, а не словами)

1. **Каркас и эталоны.** Rust workspace, сборка, тестовые эталоны коллеги
   (16 млн ячеек, 576 свежих сэмплов Excel) подключены как регрессия.
2. **xlmodel.** Чтение xlsx/xlsm потоково: shared strings, типы, shared formulas
   (перенос относительных ссылок), array/dynamic array, имена с областью. Затем XLSB.
   Критерий: книга 200 МБ читается за секунды, все 90 920 формул на месте.
3. **xlformula.** Парсер всей грамматики Excel, нормализация `_xlfn.`, относительные
   ссылки, LET/LAMBDA-переменные, массивные константы, spill-ссылки.
   Критерий: 100% формул обеих книг разбираются.
4. **xlcalc.** Векторный вычислитель и все функции, реально используемые в обеих
   книгах (~75): IF/IFS/IFERROR, INDEX/MATCH/XMATCH/OFFSET/INDIRECT/ADDRESS,
   тригонометрия, текст (FIXED/TEXT/SEARCH/MID/TEXTSPLIT/TEXTBEFORE/AFTER…),
   динамические массивы (FILTER/VSTACK/HSTACK/TRANSPOSE/SORT/UNIQUE/SEQUENCE/TOCOL),
   TREND/FORECAST, агрегаты, COUNTIF/SUMIF/SUMPRODUCT. VBA UDF (TUCSTROFFSET и др.)
   переводятся в нативные функции контракта.
   Критерий: один кейс Section_Analysis совпадает с Excel по всем ячейкам.
5. **batch.** Контракт Frame в виде конфига, многопоточный прогон всех кейсов,
   joints по свежим результатам секций, Shear Tie.
   Критерий: 16 млн ячеек = эталон, время ≤ 30 с.
6. **Скорость.** Профилирование, IR вместо обхода AST, SIMD, кэш-дружественные
   колонки, вынос инвариантов, переиспользование индексов MATCH между задачами.
7. **Excel add-in.** XLL per-user (HKCU, без админа): лента/кнопка, расчёт в фоне,
   прогресс и отмена, массовая запись результатов, понятные ошибки.
8. **Проверка как у взрослых.** Автоматический оракул: скрытый Excel считает
   случайные кейсы исходным макросом, сравнение. Дифференциальный фаззинг функций
   против Excel. Граничные нагрузки (0, ±, 1e-12, ×1000).
9. **Обобщение.** Второй шаблон (PD template, .xlsb) только конфигом; мастер,
   предлагающий контракт по VBA-циклу и драйверам.
10. **Релиз.** Установщик/обновление/удаление per-user, документация для инженеров,
    замеры p50/p95 и памяти, подпись кода (нужен сертификат компании).

## Принципы

- Ничего не подменяем «похожим» значением: неподдержанная достижимая конструкция
  останавливает расчёт с понятной причиной.
- Исходная книга никогда не меняется без явной команды; работа идёт со снимком.
- Конфиденциальные книги и эталоны не попадают в репозиторий и релиз.
