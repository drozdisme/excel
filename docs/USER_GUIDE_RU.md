# BatchCalc — руководство пользователя

BatchCalc выполняет пакетный расчёт инженерной книги Excel (перебор позиций и load cases,
который раньше делал VBA-макрос) нативным многопоточным движком. Формулы, методика и вид
книги не меняются: результаты появляются в тех же выходных листах, что и после макроса.

| Книга, команда | Исходный макрос | BatchCalc (расчёт) |
|---|---|---|
| 777P2F Frame STA403, «Run All Analysis» | ~4 часа | ~3 с (в Excel от кнопки 15–30 с) |
| PD template V6 (.xlsb), «Run Analysis», 29 отсеков × 9 414 кейсов | 2 ч 26 мин | ~11 с |

Поддерживаемые книги (контракты в папке `contracts`): Fuselage Frame Analysis и PD Skin & Stringer Analysis. Форматы `.xlsx`, `.xlsm`, `.xlsb`.

## Установка

1. Закройте Excel.
2. Дважды щёлкните `BatchCalc-Setup.exe` и подтвердите установку.
   Права администратора не нужны: программа ставится только для вашего пользователя
   в `%LOCALAPPDATA%\Programs\BatchCalc`.
3. Запустите Excel. На вкладке **Надстройки** (Add-ins) появится меню **BatchCalc**.

Нужен 64-разрядный Excel для Windows (Microsoft 365 / Excel 2016 и новее).

Удаление: **Параметры Windows → Приложения → BatchCalc → Удалить**.

## Работа

1. Откройте книгу как обычно и внесите изменения во входные данные (сохранять не обязательно —
   BatchCalc берёт текущее состояние, включая несохранённые правки).
2. **Надстройки → BatchCalc →** нужная команда, например «Run All Analysis».
   Команды повторяют кнопки на листе Controls.
3. В строке состояния виден прогресс. Excel остаётся отзывчивым, но **не редактируйте книгу
   до окончания расчёта** — результаты относятся к состоянию на момент запуска.
4. По окончании результаты записываются в выходные листы, Excel пересчитывает отчётные
   листы (MS_Table, MS_Summary, диаграммы). Сохраните книгу как обычно.

Остановить расчёт: **BatchCalc → Cancel running calculation**. При отмене или ошибке книга
не изменяется.

## Что делает BatchCalc и чего не делает

- Повторяет ровно то, что делают макросы книги (описано в «контракте» —
  файл `contracts\fuselage_frame.json`): очищает те же выходные области, записывает те же
  значения, заголовки, ошибки Excel (#DIV/0! и т.д.) и оставляет те же значения ячеек-драйверов.
- Каждая формула вычисляется по правилам Excel. Если в расчёте встретится конструкция,
  которую движок не поддерживает, расчёт остановится с понятным сообщением и книга не
  изменится — подставленных «похожих» чисел не бывает.
- Исходные кнопки и макросы книги продолжают работать; BatchCalc их не трогает.
- Отмена через Ctrl+Z результатов расчёта невозможна (так же, как после макроса).

## Проверка результатов

Для книги Frame STA403 результаты BatchCalc сравнены с результатами исходных макросов:

- все 15 937 582 значения выходных листов (MS, MS_Joint, MS_Shear_Tie, Load/Stress_Output,
  Geometry_Output, включая заголовки и ошибки Excel) совпадают, наибольшее отличие чисел
  5·10⁻¹¹ (погрешность последнего знака double);
- после запуска надстройки в Excel совпадают все 37 листов книги (около 17,6 млн ячеек);
- пересчёт всех 91 413 формул книги движком совпадает со значениями Excel.

Подробности: `VERIFICATION.md`.

## Если что-то пошло не так

- Меню BatchCalc не появилось: **Файл → Параметры → Надстройки → Управление: Надстройки Excel → Перейти**
  и отметьте BatchCalc, или переустановите. Если организация требует подписанные надстройки,
  обратитесь в IT (файл `BatchCalc.xll` должен быть подписан сертификатом компании).
- «is not a ... workbook»: активная книга не подходит ни к одному установленному контракту.
- Журнал работы: `%LOCALAPPDATA%\BatchCalc\batchcalc.log` — приложите его к сообщению об ошибке.
- Старый формат `.xls` не поддерживается — сохраните книгу как `.xlsm` или `.xlsb`.
- PD template: BatchCalc сам выполняет то, что делает кнопка Run Analysis (таблица данных по всем load case, перенастройка имён и сводных формул). Флаги YES/NO на QUICK_START учитываются. Строка журнала Analysis_Log не обновляется.

## Командная строка (для проверки и автоматизации)

```
batchcalc commands КНИГА.xlsm                 список команд контракта
batchcalc run КНИГА.xlsm --command all        расчёт без Excel (результат не записывается)
batchcalc run КНИГА.xlsm --command all --verify   сравнить с результатами, сохранёнными в книге
batchcalc selfcheck КНИГА.xlsm                пересчитать все формулы и сравнить с Excel
```
